This repository is incomplete intentionally.

The objective is business/workflow discovery, not execution.

Do not report missing CodeIgniter system/, CSS, images, fonts,
third-party libraries, uploads or generated files as defects.

They were deliberately omitted.

Do not attempt to make the legacy application runnable.

Use the source only to reconstruct:

- domain concepts
- workflows
- screens
- fields
- statuses
- validations
- database relationships
- evidence handling
- permissions
- reports/certificates that have genuine business relevance

Then design a simpler replacement application.
